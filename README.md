# Excel Sales Dashboard

## Project Overview

This project is an end-to-end Sales Dashboard created using Microsoft Excel.

The dashboard provides an interactive view of sales performance and helps analyze sales executives, total sales, target achievement, and performance against targets.

## Dashboard Features

- Total Sales analysis
- Sales Executive performance
- Target Hit % analysis
- Away From Target % analysis
- PivotTables
- Interactive filtering
- Dashboard charts
- KPI-based performance analysis

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Excel formulas
- Data filtering
- Dashboard design
